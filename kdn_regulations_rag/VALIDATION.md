- 원문 문장 및 숫자 `25000` 보존과 PDF 페이지 `[1]` 확인

## 일괄 수집·복구 기능 확인

기존 여비규정의 실제 Docling JSON을 후속 처리의 입력으로 사용했습니다. 이 일괄 처리 검증에서는 PDF 변환기와 임베딩 추론을 테스트 대역으로 교체했으며, DoclingDocument 로딩·토크나이저·HybridChunker·Chroma는 실제 라이브러리를 사용했습니다.

다음 16개 점검이 통과했습니다.

1. 하위 폴더 재귀 탐색과 대문자 `.PDF` 인식

3. ZIP 경로 이탈 및 대소문자 중복 경로 거부
4. `--list-files`에서 모델 로딩·DB 생성 없음
5. 설치된 Docling API에 맞는 변환기 설정 생성
