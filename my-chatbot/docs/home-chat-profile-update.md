# 홈 새 채팅·프로필 이미지·화면 정리

적용일: 2026-11-05.

## 변경 내용과 이유

| 변경 | 이유 |
| --- | --- |
| 홈에서 전송하는 질문은 항상 새 세션 | 홈으로 이동해도 남아 있던 sessionId·last·conversation을 재사용하여 이전 대화가 섞이던 문제 수정 |
| 홈 빠른 질문·계산폼도 새 세션 | 홈의 입력 경로마다 일관되게 새 대화를 시작하기 위해 |
| 채팅창의 후속 질문은 기존 세션 유지 | 실제 대화 중에는 최근 문맥을 이어 사용할 수 있도록 |
| 새 대화에는 previous_request_id와 이전 메시지 제외 | 앞선 답변·문의가 새 질문에 연결되지 않도록 |
| 홈 사용자 정보·상단 배지·내 말풍선의 원형 사진 | 동일한 사원 프로필을 화면 전체에서 알아볼 수 있도록 |
| 사진 오류 시 로컬 기본 이미지, 마지막으로 사람 아이콘 | 이미지가 없거나 외부 사진을 읽지 못해도 빈 공간이나 깨진 이미지가 보이지 않도록 |
| 큰 중앙 로고·장식 배경·홍보 문구 제거 | 입력창과 현재 사용자에 집중하는 간결한 홈 화면으로 정리 |
| 버튼·카드·보조 정보의 간격·색·크기 정리 | 기존 기능을 유지하면서 시각적인 복잡함을 줄이기 위해 |
| 비어 있는 관련 담당자 영역 생략 | 담당자가 없는 답변에 빈 제목과 상자가 나타나지 않도록 |

왼쪽 로고와 홈·사내 규정·문의 이력·HR 담당자·이용 안내·질문 분야 메뉴는 유지했습니다.
홈의 기존 질문 입력, 사번, 빠른 업무, 규정집 열람, 예시 질문 기능도 유지했습니다.
새 세션 생성은 입력값·사원 확인 후 실제 질문을 보낼 때 실행합니다. 홈 이동만으로 기존 DB 기록을 지우거나 대화를 강제로 종료하지 않습니다.

사진은 사원 API의 image_url을 사용합니다. 등록된 사진이 없으면 기존 로컬 기본 프로필을 사용하며 사진을 새로 생성하지 않습니다.
새 채팅을 시작하면 이전 채팅의 입력 초안도 비웁니다. 사용자 사번과 선택한 질문 분야는 그대로 유지합니다.

## 검증

별도 로컬 서버와 logs/ui-home-qa.sqlite3를 사용했으며 테스트용 n8n URL은 비웠습니다.

1. 홈에서 첫 질문 → 이전 이력 0개.
2. 같은 채팅창에서 후속 질문 → 이전 메시지 2개.
3. 홈으로 돌아가 새 질문 → 이전 이력 0개, 현재 사용자 메시지 1개.
4. 종료·평가 후 홈에서 새 질문 → 이전 이력 0개, 새 세션 생성.
5. DB에서 세션 3개가 분리되고 각각 메시지 4개 / 2개 / 2개로 보존되는 것을 확인.
6. 실제 브라우저에서 내 말풍선의 img가 로딩 완료되고 자연 너비가 0보다 큰 것을 확인.
7. 메인 서비스 8000 포트에서 변경한 HTML·JS가 제공되는 것을 확인.
8. JavaScript 문법 검사 및 기존 v7 API 회귀 테스트 12개 통과.

```console
node --check frontend_v7/app.js
python -m unittest tests.test_ui_v7 -q
```
