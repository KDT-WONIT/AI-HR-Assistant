# 계산 기능 (출장비 · 연차 잔액)

## 출장비 계산기
- 필요 입력 4가지: **출장 일수, 숙박 일수, 교통비(왕복 합계), 1박 숙박비**. 하나라도 없으면 계산하지 않고 빠진 항목을 되묻습니다.
  - 숙박 0박(당일·무박)이면 1박 숙박비는 묻지 않습니다.
  - 되물은 뒤 알려준 값은 같은 대화의 앞선 입력과 합쳐 계산합니다(최근 입력 우선).
- 계산식: 일비(직급별 정액 × 일수) + 식비(직급별 정액 × 일수, 숙박 없는 1일 출장은 2/3) + 1박 숙박비 × 숙박 일수 + 교통비
  - 일비·식비: 일반 25,000원/30,000원, 임원 30,000원/60,000원(여비규정 개정번호 38). 30일 초과 장기 출장 감액 반영.
  - 교통비·숙박비는 입력값 그대로이며, 1박 숙박비가 70,000원을 넘으면 지역별 상한 확인 안내를 붙입니다.
- 국내 출장 기준이며 해외·국외 질문은 기존 상세 계산기(날짜·거리 입력)로 처리합니다.
- 코드: `app/integrations/travel_calc.py`(입력 해석·계산), `app/agent/travel_calc_answers.py`(답변 형식)

## 연차 잔액
- 원본 데이터(`data/KDN_Enterprise_AI_Dataset/.../csv`)의 연차 잔액·사용 내역을 앱 DB로 옮깁니다.
  `python -m scripts.import_leave_data` (`--dry-run`으로 건수만 확인, 실행 전 DB 백업 자동 생성)
- 테이블: `leave_balances`(총 부여·사용), `leave_balance_details`(기본·이월·조정), `leave_transactions`(사용·승인·결재 중·취소)
- 잔여 = 기본 + 이월 + 조정 − 사용 완료(연차·반차·반반차의 USED 합계). 승인·결재 중 내역은 '예정 반영 시 잔여'로 따로 계산합니다.
- "내 남은 연차" 같은 숫자 질문은 DB 값으로 계산 과정을 보여주고, 신청 방법·규정을 함께 묻는 질문은 규정 검색 답변을 사용합니다.
- 코드: `app/integrations/leave_balance.py`, `app/agent/leave_answers.py`의 `leave_balance_answer`

## 메인 화면 출장 여비 계산기 (전체 입력 폼)

폼 제출(`task=travel_estimate`)은 `args.trip`으로 전달되어 4가지 입력 간이 계산기가 아니라 전체 계산 도구(`calculate_travel_expense`)를 호출합니다.
답변은 `app/agent/travel_estimate_answers.py`가 코드로 만들며 모델은 금액을 만들지 않습니다.

- 예상 출장비 총액
- `**{계산 내역}**` 일비·식비·숙박비(1박 인정 상한 적용 여부)·교통비·합계의 산식
- `**{적용 조건}**` 출장 구분·기간·숙박/식비 일수·적용 여비 등급
- `**{관련 규정}**` 계산에 인용된 규정 조각 원문 발췌(Chroma 조회 실패 시 생략)
- `**{확인 필요}**` 누락 입력(국외 환율 등)과 주의사항, `**{참고 문서}**` 규정 PDF·쪽수
