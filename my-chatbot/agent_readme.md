# 사내 규정 AI 에이전트

사원의 질문을 이해하고 **사내 규정 검색, 사원·조직 조회, 연차·출장비 계산**을 수행하는 업무 도우미입니다.
질문에 맞는 도구를 선택해 근거와 계산 결과를 모으고, 이해하기 쉬운 답변과 출처를 제공합니다.

## 1. 챗봇 실행 흐름

```text
사번 확인 → 질문 입력 → 사용자·대화 맥락 조회 → 도구 선택
         → 규정 검색 / DB 조회 / 계산 → 답변 작성
         → 필요 시 담당자 안내 → 대화 저장·화면 출력
```

1. **사용자 확인**: 사번으로 이름·부서·직급 등 기본 정보를 조회합니다.
2. **질문 이해**: 현재 질문과 같은 세션의 이전 대화를 함께 확인합니다.
3. **툴콜링**: Ollama가 업무 도구와 입력값을 선택하고, 서버가 검증한 뒤 MCP로 실행합니다.
4. **정보 수집**: 규정은 ChromaDB에서 검색하고, 사원 정보와 업무 수치는 DB 또는 계산 코드로 확인합니다.
5. **답변 작성**: 검색 근거·조회·계산 결과로 답변하고 문서명·페이지 등 출처를 표시합니다.
6. **후속 처리**: 근거가 부족하면 관련 담당자를 안내하고, 질문·답변·컨텍스트를 SQLite에 저장합니다.

업무 도구와 관련 없는 질문은 **일반 대화**로 처리합니다. 분야를 직접 고르거나 계산기 입력폼을 사용하면 해당 도구로 연결합니다.

## 2. 툴콜링 대상

현재 **9개 업무 도구**를 MCP로 제공합니다. 기본적으로 질문당 하나를 선택합니다.

| 도구 ID | 담당 분야 | 주요 기능 |
| --- | --- | --- |
| `hr_employment` | 인사·고용 | 채용·승진·평가·퇴직 규정, 사원 정보·연락처 조회 |
| `work_labor` | 근무·노사 | 근태·휴가·휴직 규정, 연차 잔여량·사용 가정 계산 |
| `pay_benefits` | 급여·복리후생 | 연봉·수당·복지·사택·학자금·주택융자 규정 |
| `contracts_finance` | 계약·재무회계 | 계약·공정거래·회계·내부회계 규정 |
| `audit_ethics` | 감사·윤리준법 | 감사·법무·이해충돌·인권·내부통제 규정 |
| `security_safety` | 보안·안전 | 정보보안·산업안전·사고대응·비상근무 규정 |
| `organization_management` | 조직·경영 | 직제·직무권한·이사회 규정, 부서·직원·본인 문의 이력 조회 |
| `rnd_quality` | 연구개발·품질 | 연구개발·특허·지식재산권·품질경영 규정 |
| `travel_expenses` | 출장·여비 | 국내외 출장 규정 검색, 직급과 출장 조건에 따른 예상 여비 계산 |

`general`은 일반 대화용 분기이며, 위 9개 MCP 업무 도구와 별도로 처리합니다.

## 3. 계산기 기능

| 계산기 | 입력 | 제공 결과 |
| --- | --- | --- |
| 국내 출장 간이 계산 | 출장 일수, 숙박 일수, 왕복 교통비, 1박 숙박비 | 일비·식비·숙박비·교통비와 총 예상액 |
| 출장 여비 전체 입력폼 | 국내/국외, 일정·도시·거리·등급·비용 등 해당 조건 | 적용 조건, 항목별 인정 금액, 산식·총액·관련 규정 |
| 연차 계산 | 본인 사번, 조회 연도, 선택한 사용 예정 일수 | 부여·사용·잔여량, 예정 내역 반영 결과와 사용 가정 계산 |

- **계산값은 Python과 DB 결과를 사용**하며 항목별 계산 과정을 함께 보여줍니다.
- 출장 입력이 부족하면 빠진 항목을 되묻고, 같은 대화에서 추가한 값과 합쳐 계산합니다. 무박 출장은 숙박비 입력을 생략합니다.
- 연차 원장이 없으면 입사일·직급 기준 **규정상 부여일수**만 계산하고, 실제 잔여량은 확정하지 않습니다.
- 계산은 예상액·가정 결과를 안내하는 기능이며 실제 휴가 승인, 비용 지급, 사용 기록 변경은 수행하지 않습니다.

자세한 입력·계산 기준: [계산기 설명](docs/calculators.md)

## 4. 기타 기능

- **사원·부서 찾기**: 이름·사번·부서로 검색하고 사진·직책·업무 역할·내선·이메일을 확인합니다.
- **관련 담당자 추천**: 답변 근거가 부족하면 질문의 주제·대화 맥락·부서 업무를 기준으로 문의 후보를 안내합니다.
- **근거 확인**: 규정 검색 원문, 표, 문서명·페이지와 PDF 링크를 제공합니다.
- **대화 이력**: 본인의 이전 문의를 검색하고, 같은 세션을 이어가거나 새로고침 후 복원합니다.
- **실시간 응답**: 처리 상태와 답변 미리보기를 보여주고, 단계별 처리 시간도 확인할 수 있습니다.
- **평가·외부 기록**: 별점 1~5점·오류 유형·의견을 저장합니다. n8n 주소가 설정되어 있으면 시작·질문·답변·평가/종료 이벤트도 전송합니다.

## 5. 구성과 실행

| 구성 | 역할 |
| --- | --- |
| WONIT v7 UI + FastAPI | 사용자 화면과 요청 처리 |
| Ollama | 업무 도구 선택·답변 생성. 모델명은 `.env`에서 설정 |
| MCP | 에이전트와 업무 도구 연결. 앱 시작 시 로컬 도구 서버 자동 실행 |
| ChromaDB + BGE-M3 | 규정 검색과 질문 임베딩 |
| SQLite | 사원·조직 정보 조회, 대화·평가·전송 상태 저장 |

`my-chatbot` 폴더에서 가상환경을 활성화한 뒤 실행합니다.
사원 DB·규정 인덱스와 Ollama 모델이 준비되어 있어야 합니다.

```console
python -m pip install -r requirements.txt
python -m scripts.init_db
python -m app --reload
```

- 접속: <http://127.0.0.1:8000/>
- 설정: `.env` / 전체 실행 안내: [README](README.md)
- 사번 입력은 현재 사용자 식별용이며 로그인 인증 기능은 별도입니다.
