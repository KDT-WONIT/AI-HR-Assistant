# WONIT Electronics HR Assistant — v7 로컬 통합 테스트

## 무엇이 바뀌었나

- **브랜드는 WONIT Electronics**로 유지합니다.
- 이전 v6에 포함된 한전KDN 공개 PDF를 **이번에 사용자가 직접 업로드한 `WONIT_Electronics_59.zip`의 PDF 59개**로 전부 교체했습니다.
- **사내 규정** 메뉴: 59개 전처리 PDF 원문을 10개 분야로 검색·열람하는 독립 메뉴입니다.
- **AI 질문 분야** 토글: 챗봇 요청의 `category_id`를 선택하며 규정집에서 클릭한 카테고리와 **서로 독립적**입니다.
- 팀원들이 작성한 질문 목록 **132개**를 분야별로 제공하는 접기/펼치기 UI를 추가했습니다. 클릭하면 입력창에만 들어가고, 자동 전송하지 않습니다.
- 기존 채팅방 단위 이력, 사번 조회, 연속 채팅, 스크롤, 휴가 계산, 출장비 시뮬레이션, 담당자 안내, 만족도 기능을 그대로 유지합니다.

## 중요한 제한 사항

본 ZIP은 **프론트엔드 통합 테스트 버전**입니다. `mock_server.py`가 제공하는 직원 정보·규정 질문 처리·계산은 **가상 데이터/규칙**이며 LLM·RAG·실제 원익/WONIT 사규 인증과 무관합니다.

**PDF에 주의:** 새로 받은 PDF는 파일명이 WONIT 방식으로 전처리되었지만 일부 PDF 본문에는 원출처 기관(한전KDN)의 회사명·고유 직제 등이 남아 있습니다. 원문 PDF 자체는 사용자가 제공한 바이트를 변경하지 않았습니다. **실제 WONIT 공식 사규로 단정하거나 공개 배포하지 마세요.** 배포 전 문서/데이터 담당자가 본문 전처리를 점검하고 재색인해야 합니다.

## 빠른 실행 (Windows / PyCharm)

1. 기존 v6 서버를 실행 중이면 터미널에서 `Ctrl + C`로 중지합니다.
2. ZIP 압축을 풀고 PyCharm `File → Open`에서 `WONIT_HR_UI_v7_WONIT_59_TEST` 폴더를 엽니다.
3. PyCharm Terminal에서 다음을 실행합니다.

```powershell
pwd
py mock_server.py
```

4. Chrome에서 **http://127.0.0.1:5510** 접속
5. `W-1001` 사번 선택 → 연차 질문 → AI 말풍선 결과 확인
6. `사내 규정` 클릭 → `출장 및 여비` → `여비규정` → `원문 열람` 클릭
7. `AI 질문 분야` 토글 → `연구개발 및 품질` → 홈의 `업무 분야별 질문 예시 보기` 클릭
8. 새 채팅 작성 후 `문의 이력`에서 채팅방별 저장 여부 확인

종료: `Ctrl + C`.
