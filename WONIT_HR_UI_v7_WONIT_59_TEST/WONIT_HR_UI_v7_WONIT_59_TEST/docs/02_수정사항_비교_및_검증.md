| 서비스 로고 | WONIT Electronics | 유지 |
| 규정 PDF | KDN-ID 기반 원본 PDF | **사용자 업로드 WONIT_Electronics_59.zip의 59개 PDF** |

## 테스트 기준

- PDF 수 **59개**, 분류 **10개**, 분류별 문서 수 **12 / 3 / 10 / 5 / 11 / 3 / 1 / 6 / 4 / 4**.
- 질문 예시 **132개** (`work_leave_labor` 24개, 나머지 분야 12개씩).
- 실제 PDF 열람·범위 검색은 프론트 UI/API 수준에서 구현.
- 실제 규정 문장 검색(RAG), 원출처 기관명 제거, 회사 적용 범위 판정, LLM 도구 선택·계산은 **프론트 책임 아님**.
- 로컬 가상 계산/직원 정보는 실제 회사 정보로 사용하면 안 됨.

## 확인된 원본문서 문제

- PDF 파일명은 WONIT 기준으로 전처리되었으나 본문에는 한전KDN 관련 명칭이 잔존합니다. 예: 정관 첫 페이지.
- 취업규칙 파일명의 `8울`은 원본 그대로 보관하고, **UI의 개정일 표시만 `8월`로 정리**했습니다.
- 문서 적용 가능성, 출처·조항, 개인정보/회사 고유 정보 정리는 문서 담당자가 검증해야 합니다.
