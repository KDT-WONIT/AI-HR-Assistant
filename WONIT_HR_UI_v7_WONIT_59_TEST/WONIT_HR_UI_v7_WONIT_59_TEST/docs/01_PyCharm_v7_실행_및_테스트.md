# WONIT v7 — PyCharm 처음부터 실행하기

## 1. 파일 준비

- `WONIT_HR_UI_v7_WONIT_59_TEST.zip`을 다운로드하여 압축 해제합니다.
- 기존 v6가 작동 중이라면 먼저 해당 터미널에서 `Ctrl + C`로 종료합니다.
- PyCharm > **파일(File) > 열기(Open)** > 압축 해제한 `WONIT_HR_UI_v7_WONIT_59_TEST` 폴더 선택.
- 최상위에 `index.html`, `styles.css`, `app.js`, `config.js`, `mock_server.py`, `assets/`, `regulations/`이 있어야 합니다.

## 2. 실행하기

PyCharm 하단 **Terminal(터미널)** 에서:

```powershell
pwd
ls mock_server.py
py mock_server.py
```

PowerShell에 `http://127.0.0.1:5510`이 출력되면 서버가 실행 중입니다. **서버 터미널을 닫지 마세요.**

Chrome에서 **http://127.0.0.1:5510**을 엽니다.

> 기존 `py -m http.server 5500`을 쓰지 마세요. v7은 웹파일 + API를 함께 제공하는 `mock_server.py` 서버가 필요합니다.

## 3. 사번·대화 테스트

1. 홈의 `W-1001 · 김민수` 버튼 클릭 또는 사번 `W-1001` 입력 후 Tab.
2. 상단에서 직원 정보가 확인됐는지 확인.
3. 질문 `제 연차가 며칠 남았나요?` 전송 → 가상 9일 확인.
4. 같은 대화에서 `그럼 3일 사용하면?` 입력 → 가상 6일.
5. `+ 새 대화` 버튼 → `연구개발비 규정은?` 질문 전송.
6. 왼쪽 `문의 이력` → 채팅방 2개 표시 → 첫 번째 채팅 선택 → 전체 메시지 복원.

## 4. 규정집 PDF 59개 열람 테스트

1. 왼쪽 `사내 규정` 클릭 → `전체 규정집 59건` 표시.
2. `출장 및 여비` 선택 → `여비규정` 1건.
3. `원문 열람` 클릭 → PDF 팝업, 새 창 열기·다운로드도 확인.
4. `연구개발 및 품질` 선택 → 관련 PDF 3개.
5. 규정명 검색란에 `지식재산권` 입력 → 관련 문서 필터 결과.
6. 규정집에서 분야를 바꾸더라도 **AI 질문 분야 토글의 선택 상태는 그대로**여야 합니다.

## 5. 분야별 132개 질문 예시

1. 왼쪽 `AI 질문 분야` 클릭 → `연구개발 및 품질` 선택.
2. 홈으로 이동 → `업무 분야별 질문 예시 보기` 열기 → 해당 분야 예시 12개 확인.
3. `업무 중 개발한 기술이나 아이디어를 특허로 출원하려면 어떤 절차를 거쳐야 하나요?` 선택.
4. 질문창에 자동으로 채워지고 **자동 전송되지는 않는지** 확인.
5. 원하는 경우 질문 전송. **로컬 테스트 서버는 실제 RAG가 없으므로 정확한 회사 규정 답변을 생성하지 않습니다.**
6. `근무/휴가 및 노사관리`는 예시 24개, 전체 예시는 132개입니다.

## 6. 서버 상태·오류 확인

- http://127.0.0.1:5510/api/health → JSON `ok: true`가 반환되면 서버 접근 성공.
- API 스스로 테스트: `py -m unittest discover -s tests -p 'test_local_api.py' -v`
- `Address already in use` → 이전 서버를 `Ctrl+C`로 종료.
- 접속 거부 → PyCharm Terminal에서 서버 실행 상태 확인.
- 사번 미확인 → `W-1001`, `W-1002`, `W-1003` 중 선택. 이는 가상 DB입니다.
- 실제 문서 내용을 AI가 설명하지 못함 → **정상적인 모의 서버 한계**. RAG·Agent/LLM 연결이 필요합니다.

## 7. 중요한 유의 사항

PDF 원문은 WONIT 기준으로 파일명을 정리한 전처리 실습 자료이며 일부 본문에 한전KDN 원문 표현이 남아 있습니다. 업로드된 PDF 바이너리를 변경하거나 공식 WONIT 사규로 보증하지 않습니다. 실제 운영 전 문서 데이터 담당자 확인이 필요합니다.
