# 사용자 제공 질문 리스트와 시나리오 테스트

- 질문 예시 출처: 팀원이 작성하여 사용자 메시지에 제공한 질문 목록.
- 분류: 인사·고용관리, 계약·재무회계, 감사·윤리준법, 보안·안전관리, 조직·경영관리, 연구개발·품질, 출장·여비, 근무/휴가·노사관리, 복리후생, 급여.
- 질문 예시 전체 내용은 `assets/sample_questions.json`에 있습니다. **팀원이 테스트한 질문도 실제 규정답변 보증은 아닙니다.**
- 특히 팀원 기록상 `급여명세서에 있는 수당과 공제 항목은 ...` 질문은 규정 근거를 찾지 못한 사례였습니다. 실제 RAG에서는 근거 없음 상태를 표시하고 담당자 연결이 필요합니다.

## 추천 테스트 순서

1. W-1001 조회 → 직원 정보 확인.
2. 휴가 잔여량 9일 → 5일 가정 → 3일로 수정 → 2일 추가: 모의 계산 테스트.
3. 근무/휴가 분야 선택 → 예시 질문 클릭 → 질문창에 **자동 입력만** 되는지 확인.
4. 사내 규정 메뉴 → 연구개발 분야 선택 → PDF 3개 확인 → 원문 열람.
5. 질문 분야를 출장/여비로 변경하더라도 규정집의 선택 상태가 바뀌지 않는지 확인.
6. 같은 채팅에 3회 질문한 뒤 문의 이력에서는 **1개 채팅방**으로 나오는지 확인.
7. 새 채팅으로 연구개발 질문 1회 → 문의 이력 **2개 채팅방** 확인.
8. 채팅방 클릭 → 전체 질문·답변 복원·연속 질문.
9. 채팅 종료·만족도·오류 신고 → 서버에 요청 및 저장.
10. 실제 AI 규정 해석 답변은 기대하지 말고 연결 후 별도 테스트.
