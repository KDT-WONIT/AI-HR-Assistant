# 검증 기록

검증일: 2026-11-04

## 완료한 테스트

- 도메인 계산·접근 범위·프로젝트 경로·모델 준비 테스트 44개 통과.
- 휴가·여비 계산, 사원 간 이력 차단, 담당자 미등록 처리, JSON 인자 검사를 검증.
- 현재 작업 폴더를 바꿔도 프로그램 위치를 기준으로 내부 파일을 찾는지 검증.
- 기존 외부 경로 환경변수를 무시하고 폴더 밖 경로를 거부하는지 검증.
- 모델 준비 함수의 다운로드 위치와 캐시가 프로젝트 내부인지 모의 다운로드로 검증.
- 내부 모델 파일이 준비되면 재다운로드하지 않는지, 모델·개정본이 다른 파일을 거부하는지 검증.
- 테스트용 SQLite·모델·임시 파일도 프로젝트 내부 .runtime에만 생성.

## 데이터와 모델의 구분

실제 규정 데이터는 ZIP의 data/rag_data에 포함했습니다. 실제 팀원의 사용자 DB는 아직 제공되지 않아 data/employee/employee.sqlite3에 넣어야 합니다. BGE-M3 가중치는 사용자가 선택한 최초 1회 준비 방식이며 ZIP에는 넣지 않습니다. prepare_model 명령이 models/bge-m3에 내려받습니다.

실제 BGE-M3로 새 자연어 질문을 임베딩하는 추론·검색 정확도 평가는 수행하지 않았습니다. 모델 다운로드 흐름은 가중치를 대신한 테스트 파일로 검증했습니다. MCP SDK·n8n 운영 연결은 별도 확인 대상입니다.

Windows Chroma 1.5.9에서는 한글 경로의 HNSW 로딩 문제가 확인되어 프로젝트 전체 경로는 영문을 사용해야 합니다.

## 실제 ZIP 이동 검증 완료

- 배포 ZIP을 별도 위치에 풀어 규정 DB가 실제 포함되어 있는지 확인했습니다.
- 프로그램의 작업 폴더를 프로젝트 밖으로 바꾸고, 기존 외부 DB 환경변수도 잘못된 값으로 설정했습니다.
- 내부 data/employee와 data/rag_data를 자동으로 찾고, 사원 조회와 본인 이력 조회가 동작했습니다. 사용자 DB 검증 데이터는 압축 해제한 검증용 사본에만 만들었고 배포 ZIP에는 넣지 않았습니다.
- 실제 Chroma 7,117개 청크를 확인하고 저장 벡터로 재조회하여 PDF 출처와 페이지가 반환되는 것을 확인했습니다. 새 자연어 질문 임베딩 품질 검증과는 구분합니다.
- 검증용 프로그램을 종료한 뒤 프로젝트 폴더를 다른 하위 위치로 옮기고 이름도 바꾸었습니다. 같은 외부 작업 폴더에서 다시 실행하여 동일 결과를 확인했습니다.
- 설치된 Hugging Face SDK에서 사용하는 모델 준비 API의 인자 지원도 확인했습니다. 가중치의 실제 인터넷 다운로드는 최초 준비 시 수행합니다.
